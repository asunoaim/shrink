# How we write release notes

Deadpan, self-ironic, a little unhinged, short. People should read them for fun.

1. **No brand names.** No other apps, games, companies or chat apps. Write "an app to cut, another to shrink", "your group chat", "your graphics card". The only exception is "Windows" in the install instructions, because people need the exact wording of the warning.
2. **We only roast ourselves.** Self-irony, never jokes about other tools or people.
3. **Short.** A title, a 2–3 line hook, 5–8 bullets, one closing line. Readable in 20 seconds.
4. **Simple words, deadpan tone, youthful when it fits** ("skill issue (mine)", "fr", "main character energy"). At most one joke per bullet; plain bullets are fine.
5. **2–3 emoji max, light memes** ("eventually™", "trust me").
6. **Practical info stays clear.** Install steps, the Windows warning and links are written so anyone can follow them.

Title format: `shrink X.Y.Z: <what changed, as a joke>`
